# サロン助手

サロンレポートのランキング・よく見られているキーワード・スタイル掲載文・ブログ文づくりを、iPhone だけで行うためのアプリです。

## できること
- **ランキング**：サロンレポート（PDF）を読み込むと、来店数・売上・客単価と、スタッフ／スタイル／クーポン／メニューの順位を表示。LINE に貼れるまとめ文もコピーできます。
- **キーワード**：閲覧数や予約数の多い言葉を点数順に表示。ラッコキーワードでコピーした一覧を貼り付けると「検索でも人気の言葉」も分かります。タップで選んで、スタイル・ブログづくりに使えます。
- **スタイル**：スタイル名・スタイリストコメント・メニュー内容・ハッシュタグを作るための「お願い文」を用意。
- **ブログ**：スタッフごとのタブで、その人の過去のブログをお手本にした「お願い文」を用意（イラスト画像のお願いも入れられる）。
- お願い文は ChatGPT・Gemini・Copilot・Claude の無料版に貼り付けて使います。答えを貼り戻すと、欄ごとに分けてコピーでき、注意が必要な表現もチェックします。

## 使い方（はじめの1回）
1. ランキングタブで、サロンボードからダウンロードしたサロンレポートの PDF を選ぶ
2. 設定タブの「iPhone のショートカットに登録する」を見て、よく使う画面をホーム画面に置く

## 大事なこと
- Claude で1タップ作成したい人だけ、設定タブで API キー（有料・任意）を保存できます。
- レポート（売上・スタッフ名など）と API キーは、**その iPhone の中だけ**に保存されます。インターネット上には公開されません。
- AI が作った文章は案です。投稿前に必ず内容を確認してください（効果を言い切る表現などは画面で注意が出ます）。
- ブログのお手本は、ホットペッパービューティーで公開されている記事を毎朝1回、間隔をあけて取得しています。
